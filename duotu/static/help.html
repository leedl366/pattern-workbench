1两种引擎（右上角下拉切换）

对比项程序引擎 progAI 引擎 ai
原理PIL + numpy 确定性算法：亮度重映射换材质、图案层提取+平铺换图案调 apib.ai 的 gpt-image-2，把多张参考图和提示词一起喂给模型重画
速度秒级（1~3 秒出 4 个版本）几十秒到几分钟（看模型和张数）
花费0，纯本地算力按张计费，出图前会先给你方案确认
可复现同样输入永远同样输出每次都不一样，结果有随机性
擅长换材质颜色、贴图案、清摄像头区、去底托、白底净化改结构、换角度、加/删元素、程序做不到的"重画"
不擅长不能凭空造结构、不能改视角细节可能漂移（图案走形、颜色偏），要多试几张
出几张4 个变体：A_标准 / B_更有层次 / C_更亮银白 / D_柔和自然1~4 张（面板里选）
自检数据指标打分（材质命中/图案覆盖/层次/镜头洁净）数据指标 + 视觉模型看图写点评
建议：先用程序引擎把"材质/图案/干净度"这些确定性部分搞定，实在不行再上 AI。AI 出的图也能回填成参考图，再让程序引擎精修。

2① 参考图位（图1 - 图5）

最多 5 张图，最少 2 张才能跑。上传顺序＝图号顺序。

三种放图方式

  • 点击任意空图位 → 选文件
  • 拖拽图片直接丢到图位上
  • Ctrl+V 粘贴剪贴板里的图（自动落到第一个空位）—— 截图后直接粘贴最快

支持 png / jpg / jpeg / webp / bmp。每个图位右上角有「移除」，换图直接移除再放。

角色下拉（每张图都要有个"身份"）

角色含义什么时候选它
自动识别
auto		让系统按中文语序自己猜默认。猜错了再手动改
材质源提供颜色 / 质感的那张图「把壳换成这张图的银白磨砂质感」
图案源提供要贴上去的卡通 / 印花「把这张图上的小熊图案铺到壳背」
目标底图被编辑的那张图（成品长在它身上）「把这张图的壳材质换掉」
形态底图用它当最终机身 / 外形「用这张图的整机形态」
参考图只参考，不参与计算想让 AI 看一眼但别照抄

自动识别是怎么猜的（按这个顺序）

  1. 图号附近有「整机 / 形态 / 带壳 / 机身 / 外形」→ 判为形态底图
  2. 「换成 / 改成 / 替换为 / 换为 / 改为」之后的图号，且带「材质 / 质感 / 颜色 / 银白 / 磨砂 / 金属」→ 判为材质源；「图N的材质」也算
  3. 图号附近有「图案 / 卡通 / 印花 / 花型」→ 判为图案源
  4. 「换成」之前第一个还没分配的图号 → 判为目标底图
  5. 都没命中：有图的第 2 张当目标底图，第 1 张当材质源
  6. 说了「图案不变 / 图案保留 / 保留图案 / 原图案」→ 图案源就是目标底图自己（不重新贴图，只保护原图案）
写需求的口诀：被改的图放「换成」前面，提供东西的图放「换成」后面。例：把图2的手机壳材质换成图1的银白材质 —— 图2=目标底图，图1=材质源。

上传后自动分析的信息

尺寸原图宽×高
主色量化统计出的出现最多的颜色 + 占比
中位亮度低饱和区的中位亮度 —— 判定"材质换没换成功"的核心指标，银白目标值 224

3② 历史生成图图廊

在参考图位下方，每次出图自动累加，最新在前，最多显示 80 张。

操作作用
刷新重新拉一遍服务器上的产出列表
清空全部删掉所有生成图。保留 _base.png（原始底图副本，清空后还能从原图重跑）
加入图位把这张生成图放回上面图1-图5 继续当底图/参考编辑，默认角色＝目标底图，下拉可改
✕ 删除真删文件（原图 + 缩略图一起删）
注意：把生成图回填成参考图后，建议只描述要改的那一点，别把整套动作再说一遍 —— 否则同一套动作会二次叠加，图会被压过头（发灰、发糊、层次丢失）。
技术上：「清空全部」走的是「改名搬临时回收站 → 后台线程慢慢真删」，所以点下去 0.1 秒页面就干净了，不会卡在那儿转圈。

4③ 融合需求输入框

一句话说清楚"谁 换成 什么"。下面 6 个示例 chip 点一下就填进去，可以照着改。

把图2的手机壳材质换成图1的材质，图案不变重新贴上 用图3整机形态，把图2的图案满版铺到壳背，摄像头区留白 去掉底部原托，只留小熊 图案再密一点，铺满壳背 摄像头区域再干净一点 整体再亮一点、更银白

这句话会被翻译成"动作序列"

动作触发词实际做什么
set_shape
确定形态底图		换成 / 改成 / 整机 / 形态 / 带壳整个用形态底图当最终机身外形，后续所有操作在它上面叠加。只在首次执行生效，迭代时会被自动剔除（形态不能重复设）
material_replace
材质重映射		材质 / 质感 / 颜色 / 银白 / 磨砂 / 金属提取材质源的中性区中位亮度当目标，对底图做 tanh 软压缩亮度重映射（防崩图），图案和暗部结构用羽化蒙版保护
pattern_transfer
图案迁移铺贴		图案 / 卡通 / 印花 / 贴回 / 满版 / 铺满
且没说"图案不变"		从图案源提取图案层（彩色 + 深色墨水线），按 scale/density 平铺到机身内，自动避开摄像头区并做圆角裁切
clean_cam
摄像头区清图案		摄像头 / 镜头 / 模组 ＋ 不要图案 / 干净 / 留白自动定位摄像头模组，抹掉区域内的彩色图案、恢复壳体本色，镜片暗部结构保留
remove_base
去除底托		底托 / 原托 / 托盘 / 底座不要 / 去掉…托底部 16%（base_ratio）区域用背景色羽化填充
clean_bg
背景净化		去背景 / 抠图 / 白底把非白背景统一到纯白，方便电商上架
关键规则：「图案不变 / 图案保留」＝ 换材质时保护原图案，不会触发重新贴图。想重新贴就别说"图案不变"，直接说"把图案重新贴上去 / 满版铺开"。

一句都没命中时，默认走 material_replace + pattern_transfer 两套动作。

5④ 按钮组

按钮作用
生成方案并执行主按钮。程序引擎：解析需求 → 出方案 → 一次跑 4 个变体并打分排序；AI 引擎：走 AI 出图流程
框定排除区在图上按住鼠标拖一个框 ＝ 摄像头 / 不许被贴图覆盖的区域。用这个框保存，清除回到自动识别。按钮旁会显示当前是「自动识别」还是「手动框定」
加入 AI 出图队列把当前图位 + 需求写进服务器 data/ai_queue.jsonl，不立刻出图。适合在对话里攒一批再让 AI 批量做
AI 接口设置弹窗填 apib.ai API Key（留空＝不改）和默认出图模型（如 gpt-image-2），存到服务器 /opt/duotu/data/ai_config.json
什么时候用「框定排除区」：摄像头自动识别跑偏了（图案贴到镜头上 / 该留白的地方被盖住），就手动框一下，比反复调参数快得多。

控件说明
模型下拉从 apib.ai 拉可用模型列表（缓存 15 分钟）。当前主用 gpt-image-2
张数1~4 张，默认 2。张数越多越费钱费时，但能挑到更好的
尺寸1024x1024（方）/ 1536x1024（横）/ 1024x1536（竖）/ auto
出图后 AI 自检默认勾选。出完图让视觉模型再看一遍，把「壳材质/图案一致性/有无底托/摄像头是否干净/背景是否纯/能否上架」的点评写进结果卡和对话

7⑥ 执行方案卡

跑之前先告诉你"打算怎么干"。每一步三行：标题 / 具体做什么（带真实参数值）/ 为什么这么做。

  • 程序引擎：按命中的动作逐步列，最后固定一步「数据校验与排序」（算图案覆盖、摄像头污染、中位亮度、层次跨度，按综合分排序）
  • AI 引擎：固定 4 步 —— ① 本轮基准图 ② 本轮修改要求 ③ 调用出图（模型/张数/尺寸） ④ AI 自检
  • 标题右侧灰色标签：显示本轮基准是哪张图（见第 9 节）

8⑦ 生成结果卡

按综合分从高到低排，第 1 个绿框的＝推荐版本。

每张图下面的 6 个指标

指标含义怎么看好坏
图案覆盖机身区域内彩色像素占比目标 ≈ 9~11%。太低＝没贴上，太高＝糊成一片
摄像头污染摄像头区内彩色像素占比<1% 合格 超过会标红，说明图案压到镜头了
中位亮度机身中性区（低饱和）的中位亮度银白目标 224。差得越多＝材质没换到位
层次跨度亮度的 75 分位 − 25 分位越大越立体，48 以上算满分。太低＝发灰发平
主色整图量化统计的最多颜色换银白的话应该接近 (224,224,224) 附近
白底占比接近纯白的像素比例电商主图一般希望背景够干净

基准图机制（最重要，决定"改的是哪张"）

情况本轮从哪张图起改
你在结果卡上点了「设为基准继续改」从你选的那张图叠加改（方案卡会写「你选的基准图，本轮在它上面叠加」）
没选（默认）从原始底图 _base.png 重跑 —— 不会二次累积劣化，越改越糊的问题就是这样避免的
AI 引擎优先用上一轮 AI 出的图当基准，把它和参考图一起喂给模型，并明确要求"只改本轮要求的地方，其余一律不变"

聊天框上方有一条绿色基准条，实时显示"本轮基准：xxx"，右边有「改回原图 ✕」一键清掉基准。

什么时候该点「改回原图」：连续迭代了 5、6 轮之后觉得图开始发灰/发糊/层次没了 —— 说明叠加过头了。点「改回原图」从最初的底图重跑一次，把前面的微调一次性写进需求里重做，图会立刻恢复干净。
执行阶段不再二次微调参数：「再密一点」这类词在方案阶段已经换算成参数了，点执行时直接用算好的参数，不会重复乘一次（否则你说一次"密一点"，实际会密两档）。

10角色与动作速查

写需求的万能句式

换材质把图2的壳材质换成图1的银白材质，图案不变
换图案用图3的图案满版铺到图2的壳背，摄像头区留白
换形态用图4的整机形态，其余按图2来做
做减法去掉底部原托，只留主体
做加法图案再密一点、再大一点
收尾摄像头区域再干净一点，背景改纯白

常见坑

  • 只传 1 张图 → 跑不起来，至少 2 张
  • 说了「图案不变」却又想要新图案 → 这两句冲突，去掉"不变"
  • 角色猜错 → 手动改下拉，别跟它较劲
  • 迭代太多轮发糊 → 点「改回原图」重跑
  • 摄像头老是被贴花 → 用「框定排除区」手动框

12参数表（程序引擎）

参数默认作用

13评分公式（0~100 分）

材质命中 4545 × (1 − |中位亮度 − 224| ÷ 80)　—— 越接近银白 224 越高
图案覆盖 3030 × (1 − |覆盖率 − 11%| ÷ 11%)　—— 越接近 11% 越高
层次 1515 × min(1, 层次跨度 ÷ 48)　—— 越立体越高
镜头洁净 1010 × (1 − 摄像头污染 ÷ 3%)　—— 镜头区越干净越高

按意图取不同分项：mixed（换材质+贴图案）满分 100；material（只换材质）满分 70；pattern（只贴图案）满分 80 —— 所以不同任务之间的分数不能直接横比，同一批结果里比大小就行。

用数据代替肉眼：别信"看着像换了"。看中位亮度是不是到 224 附近、摄像头污染是不是 <1%，这俩是硬指标。
