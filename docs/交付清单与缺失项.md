## 三、运行期会自动创建的目录

启动后按需创建，**不要手动建空目录覆盖**：

```
1_pattern主站/
├── data/                 accounts.db、<tid>/task.json、trim_cache
├── dtl/data/             records/ output/（每用户隔离）
├── fk/data/              records/ output/ refs/ prods/
├── aigc/data/  hd/data/  swap/data/  wm/data/
└── deliver/              交付静态页
```

各自带 72h TTL 清理线程（`_sweep` / `_expire_sweep`），删记录会连图一起删。

## 四、验收：怎样算「跑起来了」

```bash
# ① 首页
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:17700/

# ② 九个板块（未登录可能 401，200/302 都算通）
for p in "" wm/ duotu/ hd/ dtl/ fk/ swap/ aigc/ library/; do
  printf "%-12s %s\n" "/$p" "$(curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:17700/$p)"
done

# ③ 账户接口
curl -s http://127.0.0.1:17700/accounts/api/me
```

启动日志里若出现这两行，说明对应子应用**没挂上**（不致命，但功能缺失）：

```
[wm] 批量去水印子应用挂载失败：...
[duotu] 多图编辑子应用挂载失败：...
```

常见原因：`duotu/` 目录没放到主站根目录，或 `duotu` 依赖（flask）没装。
