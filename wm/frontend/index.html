① 模型引擎?云端模型都是整图处理：自动识别并抹除水印，不用圈选。
默认「内置生图通道」（开箱即用，密钥由服务端托管），也可切「魔搭免费 / 万相专能 / 自定义模型」。
本地 OpenCV / LaMa 引擎依赖水印样例定位，样例功能已下线，列表不再提供。

💡 填好 Base URL 和 API Key 后，点「拉取模型」即可从平台获取模型列表选择。

① 文件夹路径?一次处理一个文件夹：打开 / 上传新文件夹会替换当前列表（旧的自动清掉）。
· 「选择文件夹」= 从电脑里选整个文件夹，里面套多少层子文件夹都会递归读入；处理完按源目录结构镜像输出（跟 ComfyUI 一样，解压 zip 即得同构新文件夹）；
· 本机部署时也可直接填路径后点「扫描文件夹」。
