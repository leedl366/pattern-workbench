⚙️ 系统设置

① 生图站点池由图案提取 / 去水印 / 高清修复三个板块共用；②③④ 只作用于多图编辑（duotu）。保存后立即生效，无需重启；密钥脱敏回显，留空表示沿用已保存的值。

① 生图站点池 全站生图共用

多个站点 + 各自的模型清单。规则：同一个模型先在所有已启用站点里轮着试，全部失败才换下一个模型；最近成功的组合会自动排到最前，省掉必然失败的白等。某一站暂时用不了时，会自动轮到其它站点的同一个模型，无需手工切换。
⚠️ 2026-11-15 起按「参考图张数」自动分线：≥2 张原图走多图线（默认 apib → huahuaapi）， 1 张或纯文生图走单图线（默认 lensapi → huahuaapi → apib）。
两条线的站点顺序、模型顺序、超时都可以在下面「分线规则」里改，保存即生效； 这里的「模型优先级」相当于单图线的模型顺序（分线规则里留空时会用它）。
站点清单里没有的模型会自动跳过；各板块也可以用各自的顺序覆盖这里的默认值。

分线规则 按参考图张数自动选

系统会按本次任务提交了几张原图自动选线：≥2 张走多图线，1 张或纯文生图走单图线。 两条线的站点顺序 / 模型顺序 / 超时都可以在这里改，保存即生效、无需重启。
站点顺序里的名字必须和下面站点清单里的 name 一致（apib / lensapi / huahuaapi …），写错或未启用的站点会被自动忽略； 模型不在某站自己的清单里也会自动跳过。两条线都保留「熔断」：同一组合连续失败 2 次冷却 5 分钟。

② 接口与密钥 仅多图编辑

API 网关地址与密钥，两个模型共用这一套凭证。

③ 推理模型 多图编辑 · 看图 / 对话

用于识别图片内容、对话微调、方案规划等文本+视觉推理（对应 duotu 配置项 vision）。

④ 图文模型 多图编辑 · 出图

用于 AI 重绘 / 融合出图（对应 duotu 配置项 model 与 size）。模型名可从网关模型列表选择，也可手填。
